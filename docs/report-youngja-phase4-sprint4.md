## ✅ Sprint 4 디자인 Task 내역 (캐릭터별 API 키 섹션)

### 1) 캐릭터 카드 (`.agent-card`) 구현
- **요구사항 충족:** 번개 과장의 요청대로 기존 전역 API 키 카드(`.provider-card`)와 완벽하게 일관된 스타일(`var(--card-bg)`, `var(--card-border)`)을 적용하여 설정 화면 내에서 시각적 통일감을 제공합니다.
- **다크/라이트 양쪽 지원:** CSS Variable 기반으로 설계되어 모드 전환 시 자동으로 밝기/대비가 조정됩니다.
- **호버 피드백:** 마우스를 올렸을 때 살짝 리프팅(`translateY(-1px)`) 되며 섀도우가 깔리도록 추가 UX를 입혔습니다.

### 2) 캐릭터 헤더 (`.agent-header`, `.agent-emoji-bg`)
- 이모지와 이름, 프로바이더 뱃지가 나란히 예쁘게 배치되는 구조입니다.
- **이모지 배경:** 아이콘 주변에 원형의 은은한 배경 + 금색 테두리(`var(--accent-gold-border)`)를 추가해 삼국지 치비 테마의 분위기를 이었습니다.
 
### 3) 브랜드 컬러 뱃지 (`.agent-provider-badge`)
- 각 에이전트가 무슨 모델(Claude, GPT, Gemini)을 쓰는지 한눈에 알 수 있도록 둥근 알약(pill) 형태의 뱃지 클래스를 만들었습니다.
- **모델별 컬러 하이라이트:** 카드 최상단의 `data-provider` 속성과 연계되어 보라(Anthropic), 초록(OpenAI), 파랑(Google) 컬러가 알맞게 적용되도록 CSS를 세팅했습니다.

### 4) 미입력 플레이스홀더 (`.api-key-input::placeholder`)
- 번개님이 제어하는 "공용 키 사용 중"이라는 플레이스홀더 텍스트가 더 자연스럽게 보이도록 이탤릭체(`font-style: italic`) 및 음영 처리를 세세하게 손봤습니다.
