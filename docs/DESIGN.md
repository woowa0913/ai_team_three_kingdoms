## 🎨 1. Design Tokens (디자인 토큰)

이번 Phase 1 대시보드는 **"삼국지 전장의 장막"**을 컨셉으로 디자인했어요! 기존 위젯의 다크 모드 속성을 유지하면서 럭셔리한 느낌의 금색과 붉은색을 포인트로 추가했습니다.

### Colors (색상)
- `--bg-color: rgba(30, 30, 30, 0.85);` (위젯 공통 배경 - 다크 반투명)
- `--bg-overlay: rgba(15, 15, 15, 0.95);` (대시보드 메인 배경)
- `--text-color: #ECECEC;` (기본 텍스트 색상)
- `--text-muted: #8E8E93;` (보조 텍스트, 시간 표시 등)
- `--border-color: rgba(255, 255, 255, 0.1);` (구분선)
- `--accent-gold: #C9A84C;` (장막의 금색 포인트 - 하이라이트/강조)
- `--accent-crimson: #8B1A1A;` (전장의 진홍색 포인트 - 버튼/알림)
- `--message-user-bg: rgba(139, 26, 26, 0.6);` (유저 말풍선 배경 - 진홍)
- `--message-ai-bg: rgba(40, 40, 40, 0.8);` (AI 말풍선 배경 - 다크)
- `--hover-bg: rgba(255, 255, 255, 0.1);` (요소 호버 상태)

### Typography & Spacing (폰트 및 간격)
- **Font Family**: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif`
- **Border Radius**: 
  - 기본 라운딩: `12px`
  - 버블 라운딩: `16px`
- **Spacing**:
  - 기본 패딩: `16px`
  - 메시지 간격: `12px`

## 🧩 2. Component Reference (코덱스 개발자님을 위한 클래스 목록)

코덱스님! JS 작업하실 때 이 클래스명들을 그대로 사용해 주시면 찰떡같이 CSS가 입혀집니다~ 💻✨

| UI 요소 | 클래스명 | 비고 |
|---------|----------|------|
| 전체 컨테이너 | `.dashboard-container` | `body` 레이아웃 래퍼 |
| 헤더 | `.header` | 헤더 영역 컨테이너 |
| 에이전트 이모지 | `.agent-emoji` | 헤더의 아바타 구역 |
| 에이전트 이름 | `.agent-name` | 헤더의 캐릭터 이름 영역 |
| 모델 이름 | `.model-name` | 작은 글씨의 모델명 (예: gemini) |
| 헤더 버튼들 | `.header-actions` | 초기화, 닫기 버튼 래퍼 |
| 채팅 전체 목록 | **`.chat-messages`** | 메시지들이 추가될 스크롤 가능한 메인 영역 |
| AI 메시지 래퍼 | `.message .assistant` | 텍스트 왼쪽 정렬 및 다크 배경 |
| 유저 메시지 래퍼 | `.message .user` | 텍스트 오른쪽 정렬 및 진홍색 배경 |
| 메시지 내용 | `.msg-content` | 실제 텍스트가 들어갈 `div` |
| 타임스탬프 | `.timestamp` | 시간 표시 텍스트 `span` |
| 스트리밍 상태 | **`.streaming`** | 메시지 래퍼에 추가하면 커서(`▌`) 효과 적용됨 |
| 하단 입력 컨테이너 | `.input-container` | 채팅 입력창과 버튼을 감싸는 영역 |
| 텍스트 입력창 | **`.message-input`** | 멀티라인 `textarea` |
| 전송 버튼 | **`.btn-send`** | 전송 버튼. `:disabled` 속성으로 제어 가능 |
