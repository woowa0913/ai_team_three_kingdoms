# Meeting Room UI Patterns

## Layout
```
┌──────────────────────────────────────┐
│  🏢 회의실          [⚙️] [✕]        │ ← 헤더 (회의 규칙 설정)
├──────────────────────────────────────┤
│  [👤A] [👤B] [👤C] ... [+추가]      │ ← 참석자 바 (드래그 순서변경)
├──────────────────────────────────────┤
│                                      │
│  💬 회의 로그 (스크롤)               │ ← 발언 영역
│                                      │
│  [AI-A 아바타] AI-A 발언 내용...     │
│  [AI-B 아바타] AI-B 발언 내용...     │
│  ✍️ AI-C 입력 중...                  │
│                                      │
├──────────────────────────────────────┤
│  📎 [메시지 입력...]        [전송]   │ ← 사용자 입력
├──────────────────────────────────────┤
│  [👤1] [👤2] [👤3] [👤4] [👤5]      │ ← 전체 AI 목록 (클릭→참석토글)
└──────────────────────────────────────┘
```

## 발언 버블 디자인
- 각 AI별 고유 색상 (좌측 보더 컬러)
- 아바타 + 이름 + 역할 태그
- 스트리밍 타이핑 애니메이션
- 다른 AI 언급 시 하이라이트 (@멘션)

## 회의 규칙 설정
- 자유 텍스트 지침 (예: "간결하게", "데이터 기반으로")
- 최대 응답자 수 (1~N)
- 발언 순서 모드: 자동/수동/라운드로빈
- 발언 길이 제한: 짧게/보통/길게

## 참석자 관리
- 하단 전체 목록에서 클릭으로 참석 토글
- 참석 시 상단 바에 아바타 추가 (애니메이션)
- 드래그로 발언 우선순위 변경
- 비활성(휴가) AI는 반투명 처리
